# Publish Validation Checklist

Use this before publishing any post.

## Required
- [ ] Section selected.
- [ ] Theme belongs to the selected section.
- [ ] Topic belongs to the selected theme.
- [ ] Audience mapping set.
- [ ] Title is present.
- [ ] Slug is present.
- [ ] Excerpt is present.
- [ ] Arabic text is present.
- [ ] Urdu translation is present.
- [ ] English translation is present.
- [ ] Source is present.
- [ ] Main explanation is present.
- [ ] Reflection questions are present.
- [ ] Action steps are present.
- [ ] Summary is present.
- [ ] Hero image is present.
- [ ] Card image is present.

## Checks Before Publish
- [ ] Post renders correctly in the editor preview.
- [ ] Wisdom card projection updates.
- [ ] Theme page shows the post.
- [ ] Topic page shows the post.
- [ ] Student/Youth feeds show the post if mapped.
- [ ] Search can find the post.
- [ ] Related wisdom shows the correct neighbors.

## Safety Rules
- [ ] Do not publish if theme-topic mapping is incomplete.
- [ ] Do not create duplicate content for audience views.
- [ ] Do not break existing URLs or slugs.
- [ ] Do not bypass revision snapshot creation.
